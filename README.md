## 家宽 VPS 和普通香港 VPS，差的是 IP 画像

普通香港 VPS 的 IP 注册在数据中心名下，IP 数据库里标成 Hosting / Data Center。Netflix、TikTok、Instagram 这类平台看到这个标记，要么限流，要么直接拒绝登录。

香港住宅 IP VPS 的服务器还是在机房，但 IP 来自香港本地宽带运营商的住宅网段，风控系统读到的画像是“香港本地家庭用户”，欺诈值通常在 0 附近。

“双ISP”再往上加一层：IP 的 Company 和 ASN 两个字段同时登记为 ISP 类型，比只在一个字段里显示为 ISP 更难伪造，可信度更高。这类资源本身稀缺，所以价格比同配置普通香港 VPS 贵一截——你多付的钱，买的是别人风控系统里的一个标签。

丽萨主机香港三条线里，HGC 和 iCable 是双ISP住宅家宽 IP，CMI 只是 ISP 原生 IP，档次低一级。

## 三条线路怎么选：先看你的宽带是哪家

### CMI 线：三网优化，延迟优先

电信去程走 CN2 精品、联通去程走 9929、移动去程走 CMIN2，回程统一强制走 CMI 大陆优化，官网给出的大陆平均延迟约 50ms。IP 是 ISP 原生类型，能解锁香港本土 Netflix、Disney+、TVB。

这条线适合建站、中转、日常代理、大陆直连办公。它的问题也明确：IP 只是 ISP 原生，不是双ISP住宅，拿去养 TikTok 号或跑电商账号，风控识别结果不如另外两条线。

### HGC 线：双ISP住宅 + 三网优化，国内操作最稳

IP 来自 HGC（和记环球通讯），静态独享，欺诈值极低。去程电信 CN2 GIA、联通 AS4837、移动 CMI，是三条线里唯一“住宅 IP 属性”和“大陆优化线路”同时具备的。

官方页面写明可解锁 Netflix、Disney+、YouTube Premium、TVB，INS、FB、WhatsApp 营销可用。国内直接操控海外账号，这条线的实际体验最连贯。

代价是带宽给得保守：入门 50Mbps，最高 150Mbps，同价位大概只有 iCable 的一半。

### iCable 线：双ISP住宅 + 大带宽，但要接受线路定位

iCable（有线宽屏）是香港第三大宽带运营商，IP 段更小众，部分平台上的识别度更低，能解锁 TVB、Cityline 票务这类港区服务。带宽 100Mbps 起步，进阶版 200Mbps，豪华版 300Mbps。

线路这块资料口径不一致，需要分开说：官方商品页把 iCable 定位为国际 BGP 线路、**不是大陆优化线路**，明确建议通过香港或日本节点中转使用；某第三方测评则实测电信从广州走 59.43 CN2 直连、电信 47ms、移动 88ms、联通 202ms，三网去程均直连。这是单一测评的结果，与官方口径存在分歧，不要把它当成“iCable 就是 CN2 直连”来理解。稳妥做法是：按国际线路准备中转方案，下单后用自己的宽带实测。
